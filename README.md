# YEONJU — WEB PUBLISHER PORTFOLIO

> ANIME OPENING × SETTING BOOK

웹퍼블리셔 YEONJU의 개인 포트폴리오입니다.

애니메이션 오프닝의 Typography, Motion, Transition과 공식 설정자료집의 Editorial Grid, Figure, Caption 구조를 결합하여 8개의 프로젝트와 성장 과정을 하나의 작품처럼 구성했습니다.

---

## Concept

### ANIME OPENING

포트폴리오의 첫인상과 장면 전환을 담당합니다.

- Motion Typography
- Scene Transition
- Text Cut
- Mask Reveal
- Episode Intro
- Music
- Scroll Interaction

### SETTING BOOK

프로젝트 정보를 정돈된 형태로 전달합니다.

- Editorial Layout
- Project Metadata
- Figure
- Caption
- Annotation
- Responsive Study
- Development Information

Core Principle:

**MOTION ATTRACTS. EDITORIAL EXPLAINS.**

## Project Experience

각 프로젝트는 다음 흐름으로 구성됩니다.

```text id="9tcsva"
PROJECT INDEX
      ↓
EPISODE INTRO
      ↓
PROJECT STORY
      ↓
PROJECT DETAIL
      ↓
LIVE SITE
      ↓
NEXT EPISODE
```

`PROJECT STORY`에서는 프로젝트를 시작한 목적과 배경을 보여주고,

`PROJECT DETAIL`에서는 디자인, UI, 구현 과정, 반응형 화면과 결과를 Setting Book 형식으로 보여줍니다.

## Live Project Links

각 프로젝트의 실제 배포 주소는 `projects.js`의:

